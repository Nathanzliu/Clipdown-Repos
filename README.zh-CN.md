# Clipdown 🚀
> **Local-first 效率伴侣，为 Gemini 网页端而生。**

Clipdown 是一款轻量级 Chrome 插件。旨在解决 Gemini 网页端频繁出现的会话断连、网页重载导致的上下文丢失痛点，并提供无损的知识库迁移方案。

---

## ✨ 核心特性

- **原生秒存**：基于 DOM 监听，精准捕获 Gemini 划选内容与上下文。
- **Markdown 桥接**：支持 Front Matter YAML 语法，流式打包导出，完美适配 Obsidian / Notion / VS Code。
- **100% 完全离线**：数据严格存储于本地 `chrome.storage.local`，无账号、无广告、零数据追踪。
- **本地化检索**：内置模糊搜索与时间线视图。

## 📥 安装引导 (极客手动安装)

1. 前往本仓库的 [Releases](https://github.com/替换为你的GitHub用户名/clipdown/releases) 页面下载最新的 `clipdown-v1.1.1.zip` 包。
2. 在本地解压该压缩包。
3. 打开 Chrome 浏览器，访问扩展程序页面：`chrome://extensions/`。
4. 勾选右上角的 **"开发者模式" (Developer mode)**。
5. 点击左上角的 **"加载已解压的扩展程序" (Load unpacked)**，选择刚刚解压的文件夹即可。

## 🛡️ 隐私与安全声明

Clipdown 没有任何后端服务器，所有数据仅在你的浏览器本地运行。我们承诺永远不进行任何形式的数据收集与隐私追踪。
